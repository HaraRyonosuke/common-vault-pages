プライバシーポリシー

最終更新日：2026年11月24日

使う人

common-vault は開発者本人が個人で使うアプリで、本人の Google アカウントだけがログインできます。

扱うデータ

  • Google ドライブのうち、このアプリが作ったファイルと、本人が選んだファイルだけを扱います（スコープ：drive.file）。
  • ファイルの中身は本人のドライブに置いたままで、このアプリがほかの場所に保存することはありません。

データの渡し先

  • ファイルの中身は、本人の指示があったときだけ、本人が使う AI アシスタントに渡します。
  • そのほかの第三者に渡したり、売ったり、広告に使ったりすることはありません。

Google API から得たデータについて

Google API から受け取った情報の使い方は、Limited Use の要件を含む Google API Services User Data Policy に従います。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもこのアプリへのアクセスを取り消せます。
